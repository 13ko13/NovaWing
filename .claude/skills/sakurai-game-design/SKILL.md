# 桜井政博式ゲームデザイン支援

## 手順
1. 相談内容を下の対応表で分類し、該当するファイルを読む（複数可）。必ず `sakurai-knowledge/principles.md` も読む。
2. 相談に当てはまる原則と動画を選ぶ。動画は、タイトルと「使う場面」が相談に合うものに絞る。
3. 回答は次の順で書く。
   - 結論（何をどう変えるべきか）
   - 根拠（原則名と出典の動画タイトル）
   - 具体策（桜井さんの実例があれば添える。例：スマブラ、カービィ、新パルテナ、メテオス）
   - 【解釈】自分の推論や、このプロジェクトへの当てはめ
   - トレードオフ（ゲーム性 vs 一般性など、ぶつかる原則があれば）
4. 知識ベースにない内容を、桜井さんの見解として作らない。分からなければ「知識ベースには該当なし」と書く。

## 仕様書・パラメーターを書くとき
- 調整したい数値はパラメーターとして外に出す。仕様書では【パラメーター名】を口語で書き、数値は〇で示す（『パラメーターを【】でくくる』）。
- 攻撃モーションを発注するときは、待機ポーズ、攻撃ポーズ、攻撃発生フレーム、総フレームの4点を明記する（『攻撃モーションの内訳』）。

## レビューで使う質問
- 「それ、プレイヤーに事情を説明して回るつもり？」（『お客さんに説明できるの？』）
- リスクとリターンはどこにあるか。近すぎないか、遠すぎないか。
- 最初の3分で何が楽しいか。操作できない時間は何秒あるか。
- 平均化して没個性になっていないか。
