# 用語集（桜井政博のゲーム作るには）

| 用語 | 意味 | 主な出典 |
|---|---|---|
| ゲーム性 | ゲームの面白さのうち「かけひき」の部分。チャンネルでは「リスクとリターン」と定義 | リスクとリターン |
| リスクとリターン | 危険を冒すほど得られるものが大きい構造。かけひきの本質 | リスクとリターン |
| 攻略 | リスクを抑えてリターンを得るための、プレイヤー側の工夫。ゲーム性と同じものを逆の立場から見たもの | リスクとリターン／ズルを許す |
| 一般性 | 多くの人が理解して遊べる度合い。ゲーム性と反比例しがち | ゲーム性を上げると､一般性が下がる |
| ヒットストップ | 攻撃が当たった瞬間、両者を一瞬止める演出 | 大事なところはストップ!／8つのヒットストップ仕様 |
| ボスストップ | ボスを倒した瞬間に止める演出（夢の泉から実装） | 大事なところはストップ! |
| 構え／攻撃／フォロースルー | 攻撃モーションの内訳。待機→構え（予備動作・タメ）→攻撃（判定発生）→フォロースルー（後隙） | 攻撃モーションの内訳 |
| キャンセルフレーム | 待機に戻りきる前から操作を受け付けるタイミング | 攻撃モーションの内訳／フォロースルーで印象が決まる |
| フレーム | 画面の書き換え単位（通常は60fps）。時間の基準になる | フレームはコマ数／フレームを計れるようになれ！ |
| d/f | ドット・パー・フレーム。桜井氏がFC時代に使っていた速度の単位（一般的なものではない） | 速度の単位 |
| はじき入力（スマッシュ入力） | アナログスティックを倒す速さで強弱を変える入力 | はじき入力 |
| フリップモーション | 向き合った両者がどちらも正面を見せるように、ポーズを鏡像化する技術 | フリップモーション |
| 正中線 | 横画面ゲームでキャラが立つ奥行きの中心線。攻撃はここをまたぐ必要がある | 攻撃判定を常に意識／攻撃ポーズ |
| 注視点 | カメラが見ている点。キャラにぴったり追従させない | 注視点をくっつけない |
| 風切り | 剣などの軌跡に出す残像エフェクト | 風切り |
| ヒットマーク | 攻撃が当たったときに出るエフェクト | ヒットマーク |
| フラッシング | キャラや画面を光らせる演出 | フラッシング |
| ビルボード | 常にカメラの方を向く板ポリゴン | ビルボード |
| 色加算 | エフェクトで色を足す描画方法。多用するともやっとする | モヤっとさせるな |
| スクワッシュ＆ストレッチ | 扁平スケーリング。体積を保ちながら潰したり伸ばしたりする | 扁平スケーリング |
| モーション補間 | ツールがポーズの間を自動で埋める機能。ぬるい動きの原因になる | モーション補間のワナ |
| 監修 | ディレクターが成果物を確認し、修正を指示すること（レタッチ画像なども使う） | 監修あれこれ／レタッチ監修 |
| 日報／今日の一枚 | チーム内の日報ページと、1日1枚の開発スクショ | 日報のすすめ |
| チケット | タスクを担当者間で手渡すデジタル票 | チケットでタスク管理 |
| パラメーター | 調整用の数値。プログラムの外に出して、プランナーがいじれるようにする | 調整をしやすくする仕組み／パラメーターを【】でくくる |
| 【】記法 | 仕様書でパラメーター名を【】でくくり、数値を〇で書く書き方 | パラメーターを【】でくくる |
| 内圧 | 企画を誰にも話さずにためることで高まる熱量 | 内圧をカンカンに高める |
| プランB | 「Bという手もある」という併記。企画書では避ける | プランBに頼るな |
| 悪魔の釜 | 新パルテナの難易度システム。ハートを賭けて本気度を上げ下げする | 悪魔の釜 |
| ヘルパー | 星のカービィSDXの2人プレイの仕組み。主役と脇役を分ける | 星のカービィ スーパーデラックス |
| 蓄積ダメージ | スマブラの、ダメージが増えるほどふっとびやすくなるルール | 大乱闘スマッシュブラザーズ／『スマブラ』のふっとばし |
| 世界戦闘力 | スマブラSPの逆引きランキング | ランキングの功罪 |
| 名古屋撃ち | インベーダーの最下段で撃たれない現象。最大のリスクと最大のリターンが重なった状態 | リスクとリターン |
| 分解・考察・再構築 | 面白さの要素をばらし、理由を考え、組み直す発想法 | 分解､考察､再構築 |
| ノーリアクション | 入力しても何も起きない状態。排除すべきもの | ノーリアクションを排除せよ |
| 遅さは罪 | 何をするにも時間がかかることは、誰にも愛されない | 遅さは罪 |
| 平均と平凡は同じ | 強さを平均化すると没個性になるという原則 | 平均と平凡は同じ |
| アニメと実写が戦う | タッチの違うキャラが並んだときの違和感 | アニメと実写が戦うような |
| 遠景に負ける | 背景が判定のある地形より目立ってしまう状態 | 判定のあるものを強調する |
